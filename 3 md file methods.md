# Markdown Syntax Cheatsheet

| No. | Feature | Markdown Syntax Example | Output Description |
|---|---|---|---|
| 1 | Headers | `# H1`<br>`## H2`<br>`### H3` | Header levels H1 to H6 |
| 2 | Bold / Italic | `**Bold**`<br>`*Italic*`<br>`***Bold & Italic***` | Bold text / Italic text / Bold and italic text |
| 3 | Lists | `- Item 1`<br>`  - Sub Item`<br>`1. First`<br>`2. Second` | Unordered (bullet) list / Ordered (numbered) list |
| 4 | Links | `[OpenAI](https://www.openai.com)` | Clickable hyperlink |
| 5 | Images | `![Alt Text](image_url_or_path)` | Display an image |
| 6 | Code | Inline: `` `console.log()` ``. Block: see example below the table | Inline code / Code block with syntax highlighting |
| 7 | Blockquote | `> This is a quote` | Quoted (indented) text |
| 8 | Horizontal Line | `---`<br>`***` | Horizontal divider line |
| 9 | Task Lists | `- [x] Task done`<br>`- [ ] Task pending` | Task checklist |

Code block example (row 6):
```js
function greet() {
    console.log("Hello");
}
```
